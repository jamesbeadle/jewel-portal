Use only if let down by booked-in labour. Labour is always booked in advance through the JBB process.

## Process

1. Identify the need as soon as possible.
2. Email the approved agencies direct from site.
3. Provide PPE and uniform to the agency worker on arrival.
4. Induction and the full H&S procedure applied before they start work.

## Approved agencies

The current approved agency list, with contacts, is module REF-02. Confirm it with the PM; it is updated there and nowhere else.

## Email format

Title: **[Project name] – [Agency worker] – [Cost code] – [Time required]**

Body:

- Project full address.
- Labour requirement (trade, number of operatives, skill level).
- Project tasks to be completed.
- Dates and timescale required.
- The agency being asked.
- Site contact (you).

Always cc projects@jewelbb.co.uk.
