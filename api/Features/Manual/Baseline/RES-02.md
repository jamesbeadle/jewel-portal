## Skips

- Book one week in advance where possible.
- Arrange waste clearance for the same day as a material delivery wherever possible — it uses labour efficiently.
- Make sure labour is booked to clear materials and load skips.
- Make sure protection is down before the skip is dropped or removed (module STD-01).

## Muck-away

- The Site Manager books muck-away lorries and waste clearance.
- Notify the PM before booking so the cost can be confirmed.

## Approved waste suppliers

- One Waste Skips — primary.
- Skip It — secondary.
- Others as confirmed, kept in module REF-02.
